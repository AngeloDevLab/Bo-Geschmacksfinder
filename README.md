# Geschmacksfinder (bofrost)

## Überblick

Der Geschmacksfinder ist ein webbasiertes Tool zur schnellen Einordnung von Kundentypen.

Kunden beantworten wenige Fragen und erhalten ein Geschmacksprofil mit passender Produktausrichtung.

---

## Ziel

Verbesserung des Verkaufsgesprächs durch:

* schnellere Bedarfserkennung
* gezieltere Empfehlungen
* vereinfachte Entscheidungsfindung

---

## Funktionsweise

QR Code → Fragen → Auswertung → Ergebnis → Weiterleitung
